# 用户手册

## 安装与卸载

Windows 用户运行 MSI，可选择是否把 `litman` 命令行程序加入 `PATH`。新版 MSI（包括同版本但源码已变化的重构建）会直接升级已安装版本，无需手工卸载。也可直接运行无需安装的便携版 EXE；当旁边没有手册目录时，其“手册”按钮会使用内置且可搜索的中英文用户手册。如果还需要 CLI 和完整的离线 mdBook 手册，请使用便携版 ZIP。从开始菜单启动已安装的 **LitMan**。可在“已安装的应用”中卸载；卸载程序不会删除文献库或 PDF。[Windows 10 的常规支持已于 2025 年 10 月结束](https://learn.microsoft.com/en-us/lifecycle/announcements/windows-10-22h2-end-of-support-update)，但 LitMan 仍将 Windows 10 22H2 作为首要测试目标。

点击工具栏中的“关于”可查看软件版本、作者 Jingdong Zhang 和 GNU GPLv3 许可证信息。

macOS 用户可打开 DMG 后把 LitMan 拖入“应用程序”，也可运行 PKG，同时安装应用和 `/usr/local/bin/litman`。Ubuntu 使用 `sudo apt install ./litman_版本_amd64.deb`。CentOS 7 使用 `sudo yum localinstall litman-版本.x86_64.rpm`。[CentOS 7 已于 2024 年 6 月停止维护](https://www.centos.org/centos-linux/)；LitMan 的兼容性不代表操作系统仍然安全。

## 新建和打开文献库

选择“新建文献库”，指定 `library.toml` 的保存位置，再选择包含 PDF 的目录。配置和数据库存放在一起：

```toml
schema_version = 1
database = "literature.sqlite3"
library_root = "../pdfs"
language = "system"
```

数据库名必须解析为配置文件旁的文件。相对根目录从配置文件目录开始解析，也可使用绝对目录。扫描会包含所有子目录。

## 扫描

打开文献库后会自动进行增量扫描。“扫描”可再次执行；“刷新元数据”还会重新读取未改变文件的内嵌元数据。扫描具有以下规则：

- 不跟随目录符号链接，并拒绝规范路径位于根目录之外的文件；
- 根据文件大小和修改时间跳过未改变文件；
- 对新增或改变的文件计算 BLAKE3 哈希，并识别唯一明确的移动；
- 缺失文件的记录和元数据仍然保留；
- 相同内容的多个副本会被标记，但不会自动合并；
- 损坏或加密文件的错误只记录到该文件，不会中断整个扫描。

扫描期间界面仍可使用，并可点击“取消”。取消后已经完成的记录会保留，可以随时继续扫描。

## 元数据与手工修订

选择论文后，可编辑标题、按顺序排列的作者、摘要、出版日期、期刊或会议、卷、期、页码、DOI、URL、语言、按顺序排列的关键词以及备注。界面中的作者和关键词使用分号分隔，然后点击“保存”。

LitMan 会读取 PDF Info 和常见 XMP、Dublin Core、PRISM 字段。最终显示值的优先级如下：

1. 用户手工值；
2. XMP 值；
3. PDF Info 值；
4. 空值。

重新扫描绝不会覆盖手工值。“恢复 PDF 元数据”会删除指定字段的手工覆盖，让当前内嵌值重新显示。没有元数据时，文件名仅作为界面占位文字；除非用户输入，否则不会保存成题名。

## 查找和整理文献

搜索会在元数据、作者、关键词、备注、文件名/路径和分组名中进行字面匹配。文本先进行 Unicode NFKC 规范化并转换为小写。中文使用子串搜索，不依赖中文分词。

可创建类似 `课题/方法` 的嵌套分组。一篇论文可以属于多个分组。在中间列表中单击一行以选择文献，或按住 Ctrl/Command 单击以多选。然后在左侧始终可见的“将所选文献加入分组”区域选择目标分组，并点击“加入分组”或“从分组移除”。单击分组树中的分组只会筛选列表，不会把文献加入分组。要删除所选分组及其所有嵌套分组，请点击“删除所选分组”并确认。分组关系会被移除，但不会删除文献记录或 PDF。

拖动各列表头之间的分隔线可调整文献列表列宽。调整后的列宽在当前 LitMan 运行期间保持有效。

重要程度可以为空，也可以选择一至五星，五星表示最重要；`×` 用于清除。多选后可批量修改。英文显示 **Importance**，简体中文显示 **重要程度**。

状态筛选可显示存在、缺失或出错的记录。重要程度、分组和搜索条件可以组合使用。

## 打开与移除

“打开”会调用操作系统的默认 PDF 阅读器。“移除数据库记录”经确认后仅删除 LitMan 中的记录。LitMan v1 没有任何修改、移动或删除 PDF 的功能。

## 备份、复制与恢复

程序运行时使用“备份”或 `litman backup 目标目录`。该操作通过 SQLite 在线备份 API 创建一致的配置/数据库文件对。如果直接复制文件，必须先关闭所有 LitMan 进程，再同时复制 TOML 和 SQLite 文件。

换电脑时，复制或挂载 PDF 目录，打开复制后的 TOML，然后选择“更改根目录”或执行 `litman root set 目录`。数据库内的相对 PDF 路径统一使用 `/`，因此只需更改根目录。不要把不同备份中的配置和数据库拼在一起。

恢复时关闭 LitMan，用同一次备份中的两个文件替换现有文件。在恢复库成功打开并扫描之前，请保留额外副本。

## 升级与错误处理

旧版程序可能拒绝打开新版数据库。升级前请先备份。数据库迁移在事务中完成，并且不会改变 PDF。

文件显示缺失时，请检查根目录后重新扫描。解析错误会保留诊断信息，必要时仍可手工输入元数据。数据库繁忙时，请关闭其他 LitMan 进程再重试。如果 Windows 上 GPU 渲染器初始化失败，LitMan 会自动改用 OpenGL 重试。

所有数据均保存在本地。LitMan 没有遥测，运行时不需要网络连接。
