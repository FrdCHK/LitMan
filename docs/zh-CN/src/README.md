# LitMan 手册

LitMan 用于管理已经存放在本地目录中的 PDF 论文。它能够扫描文档内嵌元数据，让用户在不更改 PDF 的前提下补充或纠正信息，并使用嵌套分组和 1–5 星重要程度整理文献。

LitMan 的作者是 Jingdong Zhang，并采用 GNU 通用公共许可证第 3 版（GPLv3）。完整许可证位于 `LICENSE`，也会包含在每个发行包中。

这些手册会生成为支持搜索的离线 HTML。安装包同时包含完整的简体中文版和英文版。

- 普通用户请先阅读[用户手册](user.md)。
- 命令行用户可查看[命令行参考](cli.md)。
- 贡献者请阅读[开发手册](development.md)。
- 发布工程师请遵循[构建与发布手册](building.md)。

LitMan 不会修改、移动或删除任何 PDF。所有可编辑信息都保存在配置文件旁的 SQLite 数据库中。
